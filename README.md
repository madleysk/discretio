# Discretio — Private Encryption and Security Tools

Discretio is a suite of private, offline, on-device encryption and security tools for Android, built around an encrypted vault.

- **Offline by design:** no server, no account, and no syncing. Your data never leaves your device.
- **Strong encryption:** AES-256-GCM for files and AES-256-XTS for hidden, VeraCrypt-compatible containers. Keys are derived from your master password with Argon2id/PBKDF2.
- **Zero-knowledge:** no one but you can access your data, including the developers.
